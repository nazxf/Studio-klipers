# Impeccable Required

Studio Klipers must use Impeccable style guidance for all UI work.

Install the skill in the coding environment:

npx skills add pbakaus/impeccable

Before coding UI, the agent must read:

- AGENTS.md
- docs/DESIGN-SYSTEM.md
- docs/IMPECCABLE-STYLE.md
- docs/CODEX-PROMPTS.md
- IMPECCABLE.md

Required design direction:

- premium dark charcoal dashboard
- neon lime accent
- clean creator workflow
- subtle Framer Motion animation
- calm spacing
- strong hierarchy
- polished cards and buttons
- useful empty states
- no generic AI UI
- no random gradients
- no clutter

Mandatory prompt for Codex:

Use Impeccable in product UI mode. Read AGENTS.md, docs/DESIGN-SYSTEM.md, docs/IMPECCABLE-STYLE.md, docs/CODEX-PROMPTS.md, and IMPECCABLE.md. Before coding, give me the Phase 1 plan and list the files you will create or change.

After UI implementation, run an Impeccable-style audit and polish the UI before moving to backend work.
